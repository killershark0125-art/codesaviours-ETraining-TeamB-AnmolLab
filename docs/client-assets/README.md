# Anmol Lab — Client Assets

This folder stores client-supplied brand assets, confirmed contact details, working brand-color samples, and the outstanding content checklist for the Anmol Lab website.

## Start here

- [`lab-info.md`](lab-info.md) — consolidated client information transcribed from the supplied report/logo images.
- [`brand/colors.md`](brand/colors.md) — sampled colors and CSS variables.
- [`research/content-needed-from-client.md`](research/content-needed-from-client.md) — items to obtain or confirm with the client.

## Folder map

- `logo/` — transparent logo, white logo, microscope icon, and favicon files.
- `brand/` — color palette documentation and swatches.
- `data/` — CSV templates for the client-approved test catalog and packages.
- `research/` — client-content gaps and provenance notes.

## Important

The logo assets were extracted from coordinator-supplied JPEG screenshots. They are raster extractions, not original vector artwork. Ask for the original logo file if available. Color values are sampled approximations, not an official brand guide. Do not use the old Sadiqabad research; that was a different similarly named laboratory.
